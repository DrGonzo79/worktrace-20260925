# Phased build prompts

## Phase 1 — paid pilot operations

Build buyer brief intake, a versioned task schema, worker/site consent, signed resumable uploads, checksum validation and a human QA queue. Persist an immutable lineage manifest. Prove one paid task end to end before automating labels.

## Phase 2 — assisted curation

Add model-assisted shot boundaries, transcript, face/screen/address detection, and tool/action proposals. Require reviewer approval, store model/version/confidence, measure suggestion precision and never auto-release flagged media.

## Phase 3 — repeat network

Add buyer acceptance rules, coverage maps, worker credentials, site reuse, payouts, disputes, revocation/retention controls and per-task economics. Expose search only across licensed, accepted segments; enforce tenant and license boundaries in every query.

## Phase 4 — production hardening

Threat-model contributor uploads and insider access. Add OIDC/RBAC, per-tenant encryption, malware scanning, audit export, deletion workflows, SLOs, tracing, dead-letter recovery, cost budgets and disaster-restore exercises. Gate deployment on privacy and labor counsel review.
